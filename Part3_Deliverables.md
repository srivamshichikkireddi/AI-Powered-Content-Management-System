# Software Engineering — Mini-Project Deliverables Part-3 (transcription of the course PDF)

## 1. Test Cases Updation
a. Update the test cases written by you earlier based on the changes made during the sprints.
b. Update the Test Case Document accordingly.

## 2. Testing [2nd Nov to 6th Nov]
a. Complete all the testing according to the Test Plan
b. Generate all the Test Reports covering the following
   i. Unit Test Report
   ii. System Validation Report
   iii. Code Coverage Report
   iv. Branch Coverage Report
c. Upload all the reports to the docs folder in the project repo.

## 3. Optional Sprint-3 - Parallel Activity [2nd Nov to 6th Nov]
a. If there is another Sprint required due to spill overs then complete the development during this week and call it as Sprint-3.
b. Parallelly complete the testing and generate the reports also.
